# Аль-Баян — Quran Learning PWA

**Status: in development / local prototype**

Аль-Баян — progressive web app для ежедневного изучения Корана на русском языке. Проект объединяет чтение, пословный разбор, таджвид, аудио, тренировку слов, Киблу и обучение намазу в одном интерфейсе.

## Реализовано

- дизайн «Ночной сад»: нижняя панель вкладок (Путь, Коран, Слушать, Намаз, Профиль), путь уроков в виде тропы с пройденными, текущим и закрытыми аятами, полноэкранный урок из 4 шагов с подсветкой слова во время чтения, переходом по словам и повтором ×1/3/5;
- интерактивный Quran reader с выбором аята;
- пословный и смысловой перевод;
- режимы Tajweed и Hifz;
- аудиоплеер с изменением скорости и повтором;
- Qibla compass: выбор города и GPS-режим;
- пошаговое обучение омовению и намазу: иллюстрации 8 положений тела и все молитвы каждого положения (арабский текст, транскрипция, перевод); тренажер из 13 молитв;
- daily lesson из четырёх шагов: слушание → разбор слов → quiz → tadabbur;
- word quiz, словарь и прогресс изучения;
- заметки к аятам;
- «Коран отвечает»: вопрос или состояние (тревога, грусть, утрата, гнев…) → подходящие суры с описанием, ключевым аятом и прослушиванием всей суры (повтор, таймер сна); путеводитель по всем 114 сурам;
- «Слушать и заучивать»: все 114 сур (арабский текст, транскрипция, перевод Кулиева), чтение аят за аятом с повтором ×1/3/5/10, режим скрытия слов и проверка записи по памяти, прогресс хифза;
- streak, score и learned words в localStorage;
- speech synthesis для озвучивания;
- PWA manifest / standalone mode.

## Stack

- HTML
- CSS
- JavaScript ES modules
- Web APIs: Geolocation, Speech Synthesis, localStorage
- PWA manifest

## Данные Корана

Тексты сур лежат в `data/quran/` (см. `data/quran/LICENSE.md`): мусхаф Медины (риваят Хафс), транскрипция Tanzil.net, перевод смыслов Эльмира Кулиева. Пересборка: `python3 scripts/build-quran-data.py`.

## Product idea

Главная продуктовая идея — не просто показать текст Корана, а построить короткий ежедневный learning flow вокруг одного аята: услышать, понять слова, проверить себя и зафиксировать размышление.
