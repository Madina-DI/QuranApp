# Аль-Баян — Quran Learning PWA

**Status: in development / local prototype**

Аль-Баян — progressive web app для ежедневного изучения Корана на русском языке. Проект объединяет чтение, пословный разбор, таджвид, аудио, тренировку слов, Киблу и обучение намазу в одном интерфейсе.

## Реализовано

- интерактивный Quran reader с выбором аята;
- пословный и смысловой перевод;
- режимы Tajweed и Hifz;
- аудиоплеер с изменением скорости и повтором;
- Qibla compass: выбор города и GPS-режим;
- пошаговое обучение омовению и намазу;
- daily lesson из четырёх шагов: слушание → разбор слов → quiz → tadabbur;
- word quiz, словарь и прогресс изучения;
- заметки к аятам;
- streak, score и learned words в localStorage;
- speech synthesis для озвучивания;
- PWA manifest / standalone mode.

## Stack

- HTML
- CSS
- JavaScript ES modules
- Web APIs: Geolocation, Speech Synthesis, localStorage
- PWA manifest

## Product idea

Главная продуктовая идея — не просто показать текст Корана, а построить короткий ежедневный learning flow вокруг одного аята: услышать, понять слова, проверить себя и зафиксировать размышление.

## Status

Проект находится в разработке. Публичный production-deploy и окончательная верификация контента ещё не заявляются как завершённые.
